# Growth Skills

A curated directory of growth skills, distilled from the best publicly available
growth playbooks (Reforge / Brian Balfour, Elena Verna, Andrew Chen, Casey Winters,
Sean Ellis, and the PLG canon) into actionable, agent-usable `SKILL.md` files.

Each subdirectory is a self-contained skill with YAML frontmatter (`name`,
`description`) and a body of frameworks, checklists, and formulas.

## Skills

| Skill | What it's for |
|-------|---------------|
| [`growth-strategy`](growth-strategy/SKILL.md) | Pick where growth comes from: Four Fits, growth loops vs. funnels, the Racecar framework, and a North Star Metric. |
| [`plg-metrics`](plg-metrics/SKILL.md) | Build the metrics tree: AARRR pirate metrics, the PLG flywheel, North Star + input levers. |
| [`activation-onboarding`](activation-onboarding/SKILL.md) | Get new users to the "aha moment" fast — map the activation path, cut time-to-value. |
| [`retention-lifecycle`](retention-lifecycle/SKILL.md) | Keep users: cohort retention curves, the smiling/flattening test, lifecycle messaging. |
| [`acquisition-channels`](acquisition-channels/SKILL.md) | Find and scale channels: product-channel fit, channel selection, CAC/LTV discipline. |
| [`referral-viral-loops`](referral-viral-loops/SKILL.md) | Design referral and viral loops, model k-factor and cycle time. |
| [`growth-experimentation`](growth-experimentation/SKILL.md) | Run trustworthy experiments: hypotheses, ICE/RICE, sample size, significance, no-peeking. |

## How to use

Point an agent (or yourself) at the skill that matches the job. Each skill is
framework-first: it tells you which model applies, the formula or checklist to run,
and the common traps. Start with `growth-strategy` to decide *where* to grow, then
`plg-metrics` to instrument it, then the loop-specific skills to execute.
