# Skill Packs

**Packs** are pre-assembled rosters — a handful of skills that fit a role, so you can
stand up a useful Bot in one go instead of picking skills one at a time.

Each pack lists the skills it bundles (with links) and a suggested routine cadence. Mix
and match freely; a pack is a starting point, not a fence.
