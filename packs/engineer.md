# Engineer Pack

For product and platform engineers. Your Bot reproduces bugs, orchestrates agent runs,
watches performance, and spins up prototypes.

## Skills

- [Bug Reproduction](../skills/engineering/bug-reproduction/SKILL.md) — reproduces in staging, drops a repro pack.
- [Cloud Agent Orchestrator](../skills/engineering/cloud-agent-orchestrator/SKILL.md) — launches, monitors, unsticks runs.
- [Playtest Operator](../skills/engineering/playtest-operator/SKILL.md) — brute-forces UI flows, returns findings.
- [Product Performance](../skills/engineering/product-performance/SKILL.md) — walks flamegraphs, ranks hotspots.
- [Prototype Builder](../skills/engineering/prototype-builder/SKILL.md) — ask → clickable prototype + live URL.

## Suggested cadence

- **On bug report:** Bug Reproduction.
- **Before release:** Playtest Operator.
- **Weekly / on regression:** Product Performance.
- **On demand:** Cloud Agent Orchestrator, Prototype Builder.
