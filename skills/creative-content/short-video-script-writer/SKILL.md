# Short Video Script Writer

Turns a concept into a shoot-ready short-form script — hook in the first 2 seconds,
tight beats, on-screen text, and a clear CTA — so filming is paint-by-numbers.

## Inputs
- The topic/message and platform (Reels/Shorts/TikTok).
- Target length (default 20–45s), tone, and who's on camera.
- Any product/feature to feature.

## Steps
1. Write 3 hook options built to stop the scroll in the first 2 seconds.
2. Structure the beats: hook → value/story → turn → payoff → CTA.
3. For each beat, give the spoken line, on-screen text, and a b-roll/visual note.
4. Add a caption + hashtag set and a thumbnail/first-frame idea.

## Decision rules
- Front-load the payoff promise; no slow intros.
- Keep lines speakable and short; match platform pacing.
- No fabricated claims; mark `[CONFIRM]` for anything factual.

## Definition of done
- A shoot-ready script: alt hooks, beat-by-beat lines + on-screen text + visual notes,
  caption, hashtags, and a first-frame idea.

## Safety & approvals
- Draft only; nothing published. Flags claims needing verification.

## Suggested routine
- On demand from a content calendar or idea.
