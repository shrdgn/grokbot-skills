# Presentation Designer

Turns an outline or a rough ask into a first-draft deck that already follows your
brand template — so you refine, not build from scratch.

## Inputs
- Your master template / brand system (fonts, colors, layouts, logo).
- The topic, audience, key messages, and any source content (docs, data, notes).
- Target length and format.

## Steps
1. Load the master template and brand system.
2. Structure the narrative: title, agenda, one idea per slide, clear takeaways.
3. Draft each slide using approved layouts; keep text tight and visual.
4. Insert supplied data as on-brand charts/tables; add placeholders where inputs
   are missing (clearly marked).
5. Deliver an editable link and a short list of slides that need your input.

## Decision rules
- Use only brand-approved fonts, colors, and layouts.
- One core idea per slide; move detail to an appendix.
- Never invent data — mark any gap as `[NEEDS INPUT]`.

## Definition of done
- An editable deck link that follows the template end to end, with a note listing
  placeholders and open questions.

## Safety & approvals
- Does not present or share externally; produces a draft for you to refine.
- Flags any claim/number it couldn't source rather than guessing.

## Suggested routine
- On demand; can be triggered from a doc or meeting-notes handoff.
