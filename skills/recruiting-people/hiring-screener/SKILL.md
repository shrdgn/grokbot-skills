# Hiring Screener

Screens applications and work samples against a defined, role-specific bar and hands
back an ATS-ready review, so interviewers spend time only on strong candidates.

## Inputs
- Role scorecard / must-haves and nice-to-haves.
- Applications and any work samples/assignments.
- Fairness/consistency rules.

## Steps
1. For each candidate, evaluate against the scorecard criteria.
2. Score each criterion with specific evidence from the application/sample.
3. Recommend advance / hold / decline with a rationale.
4. Write an ATS-ready review note per candidate.
5. Batch results for recruiter review.

## Decision rules
- Score strictly on the defined bar; apply criteria consistently to every candidate.
- Evidence-based only — cite the resume/sample; never infer protected attributes.
- Borderline → hold for human review, never silent auto-decline.

## Definition of done
- A scored, evidence-backed review per candidate with an advance/hold/decline
  recommendation, ready to sync to the ATS after recruiter sign-off.

## Safety & approvals
- **Recommendations only — a human makes the decision.** No auto-rejections.
- Ignores protected characteristics; flags anything that risks bias.

## Suggested routine
- Triggered on new applications, with a daily batch review.
